# 신한 계좌 조회·발주 대조

관리자 → 발주 집계 → 계좌내역·발주 대조. 조회 기간은 최대 93일(앱 제한).
현재 선택된 푸드/카페/매점 발주만 대조한다. 같은 계좌를 여러 사업장에 연결하면
다른 사업장 연결 여부는 이 화면에서 검증하지 못하므로 담당자가 확인해야 한다.

Supabase `nmf-access`에 아래 시크릿을 등록한다. 실제 값을 소스, 채팅, 로그에 넣지 않는다.

- `BANKAPI_API_KEY`
- `BANKAPI_SECRET_KEY`
- `BANKAPI_SH_LOGIN_ID`
- `BANKAPI_SH_LOGIN_PASSWORD`
- `BANKAPI_SH_ACCOUNT_NUMBER` (하이픈 제외)
- `BANKAPI_SH_ACCOUNT_PASSWORD` (4자리)

신한은 `/v1/transactions/login`의 `accounts` 배열을 사용한다.
인터넷뱅킹 간편계좌관리에 등록된 계좌가 필요하다. 기업뱅킹 ID의 호환 여부는
공급자 문서에 별도로 보장되어 있지 않으므로 실제 계정 등록 후 1회 확인해야 한다.
문서: https://bankapi.co.kr/docs

브라우저는 기간만 전송하고 기존 HMAC·관리자 세션으로 인증한다.
`x-region: ap-northeast-2`로 서울 실행을 요청한다. 실제 국내 IP 허용 여부는 배포 후 확인한다.
서버는 비밀값과 원문 오류를 반환하지 않는다. 자동 재시도는 하지 않는다.
동일 계좌 조회는 공급자 제한(5분)에 따르며 브라우저에도 대기시간을 표시한다.

조회 원문은 메모리에만 유지한다. 출금 중 동일 금액·날짜 ±7일 발주를 후보로 제시하며,
관리자가 확인한 연결만 발주의 `paymentBank`와 `paymentBankAt`에 저장한다.
은행 거래 ID가 없으므로 계좌+거래 필드의 SHA-256으로 참조를 만든다. 필드가 바뀌면
기존 연결과 매칭되지 않을 수 있고, 구분 불가능한 동일 거래는 수동 연결을 막는다.
연결 참조는 관리자 전용이며 일반 사용자 projection에서는 제거한다.
연결·해제는 발주 합계, 비용, 미수금, 지급 완료 상태를 바꾸지 않는다.
입금·환급은 발주 결제로 자동 연결하지 않으며, 미연결 출금은 누락 확정이 아니다.

배포 준비: `nmf-access` 배포와 함께 로컬 평문 앱을 기존 앱 비밀번호로 암호화하여
`index.html`/`ver.json`을 재생성한다. 키 등록 후 실제 조회·권한·국내 IP를 확인한다.

# 나모푸드 식단 작성 매뉴얼

기준일: 2026-10-08 · 적용 대상: 조식·중식·석식·야식 자동 편성과 미제공 AI 식단 보정

## 1. 운영 방향

한 끼 10,000원. 일반 함바보다 높은 가격을 **확실한 주찬의 품질과 ‘메인이 하나 더 있는’ 구성**으로 설명할 수 있어야 한다. 공장 근무자가 식판을 받았을 때 먹을 것이 많고 든든하다고 느끼는 급식이다. 가짓수만 늘린 나물·샐러드 위주의 가정식, 같은 재료 이름만 바꾼 메뉴 나열을 피한다.

이 기준은 AI 초안 자체를 좋은 식단의 근거로 삼지 않는다. 현재 저장 자료와 9/28·10/1·10/4·10/7 저장본을 비교해 **사람이 바꾼 것으로 확인된 22끼** 중 명확한 구성 사례를 참고했다. 과거 식단의 오타·임시 입력·칸 배치 오류까지 정답으로 복제하지 않는다.

## 2. 한 끼의 기본 구성

- 쌀밥은 기본 제공. 별도 반찬 수나 추가 주찬으로 세지 않는다.
- 편집 기본 칸은 국·메인1·메인2·부찬1·부찬2·부찬3의 6칸이다. 추가·제거 가능한 기존 편집 방식은 유지한다.
- 메인1·메인2는 각각 따로 배식할 수 있는 실속 있는 주찬이다. 육류·생선·해물 중심 메뉴를 우선 조합하고, 적어도 하나는 확실한 육류·생선·해물 주찬으로 한다. 두부·달걀만으로 두 메인을 채우지 않는다.
- 여기에 **주찬급 보강 메뉴 1개 이상**을 더한다. 닭강정, 고기완자·동그랑땡, 고기/해물 만두, 생선튀김, 계란말이·계란찜, 두부양념구이 등 실제로 배식할 수 있는 단백질 중심 메뉴다. 보강 메뉴는 부찬 칸 또는 추가 칸에 둘 수 있다. 자동 편성은 기본적으로 추가 칸을 활용한다.
- 김치 1종과 서로 다른 곁들임을 갖춘다. 샐러드·쌈·장아찌는 주찬에 맞게 붙인다. 김치·국·감자튀김·나물·과일·음료·후식은 ‘메인 하나 더’로 계산하지 않는다.
- 국은 실제 국·탕·찌개다. 국수·우동·라면을 국 칸에 넣지 않는다. 국물에 고기가 들어간다고 별도 주찬을 빼지 않는다.

**기본형:** 쌀밥 + 국 + 주찬 2종 + 곁들임 2종 + 김치 + 주찬급 보강 1종.

이는 자동 편성의 품질 기준이지, 사람이 작성한 식단을 강제로 덮어쓰거나 추가·제거를 막는 규칙은 아니다.

## 3. 실제 수정 식단에서 가져온 구성 원칙

| 확인 사례 | 주찬 구성의 참고점 |
| --- | --- |
| 10/5 석식: 고등어구이·위샹로우스·닭강정 | 생선 + 고기볶음 + 인기 있는 닭요리로 체감 주찬을 세 종류 확보. 닭강정은 부찬 칸에 있어도 주찬급 보강으로 본다. |
| 10/6 석식: 대패삼겹콩나물볶음·동그랑땡·왕교자튀김 | 확실한 고기 주찬에 전/완자·만두를 더해 식판이 풍성해지는 구성. |
| 9/30 중식: 고추장삼겹·만두튀김 초고추장무침·탕수육·새우튀김 | 고기·튀김·해물을 보강하는 방향을 참고한다. 튀김을 한 끼에 모두 복제하지 않고 작업량과 식감을 나눈다. |
| 10/8 중식: 훈제오리무쌈·깐풍새우, 부추무침·겉절이 | 주찬 재료와 조리법을 다르게 하고, 무쌈·부추·겉절이를 해당 주찬에 맞춰 붙인다. 자동 편성에서는 주찬급 보강을 하나 더 검토한다. |

사례는 긍정적인 조합을 추출하기 위한 자료다. 해당 식단 전체가 새 자동 편성 기준을 모두 통과했다는 뜻은 아니다.

## 4. 퀄리티와 조합

- 익숙하고 실제 급식에서 설명 가능한 이름을 쓴다. 제육·수육·불고기·닭갈비·찜닭·닭강정·돈가스·탕수육·생선구이/조림·오징어볶음 등의 주찬군을 바탕으로 조리법과 양념을 바꾼다.
- 서로 다른 단백질과 조리법을 조합한다. 예: 고기볶음 + 생선구이 + 계란말이, 수육 + 매콤한 해물요리 + 고기만두. 같은 양념 볶음 셋 또는 튀김 셋으로 채우지 않는다.
- 달걀·두부·소시지·만두는 좋은 보강 수단이지만, 값싼 보강 메뉴만 늘려 메인 재료를 줄이는 방식으로 쓰지 않는다. 고기 몇 조각이 들어간 채소볶음도 고기 주찬으로 과대 계산하지 않는다.
- 이름에 ‘수제·특선·프리미엄’만 붙여 품질을 주장하지 않는다. 실제 주재료 양, 크기·손질 상태, 식감, 소스 별도 제공, 배식 직전 마무리로 품질을 만든다.
- 계절에 맞는 곁들임을 사용한다. 낯선 채소 조합을 무작위로 늘려 다양성을 채우지 않는다.
- 꽃게·장어·고가 스테이크 등 비싼 재료만 연속 편성하지 않는다. 구체적인 원가는 발주 단가·손질 수율·식수에 따라 현장에서 확인한다. 이 매뉴얼이 원가나 실제 제공량을 보증하지는 않는다.
- 영양 균형은 최우선 편성 기준이 아니지만 식품 안전은 생략하지 않는다. 술·주류형 음료는 모든 칸에서 제외한다.

## 5. 주간 다양성과 대량 조리

- 앞뒤 7일의 모든 끼니·모든 칸·추가 메뉴를 확인한다. 새 메인과 주찬급 보강은 같은 음식/별칭을 이 기간에 반복하지 않는다.
- 제육볶음/돈육고추장볶음, 돈가스/돈까스처럼 실제로 같은 음식은 하나로 본다. 간장불고기와 고추장불고기처럼 실제 조리가 다른 메뉴는 구별한다.
- 한 끼 안에서 음식과 단백질·조리법·양념 조합이 겹치지 않게 한다. 같은 조합은 하루 최대 2회로 제한한다.
- 하루 4식의 국과 김치 외 곁들임을 나누고, 앞뒤 3일을 포함하는 7일 안에서 같은 국/곁들임은 최대 2회로 한다. 밥·김치는 반복 가능하다.
- 100~500인분을 회전솥·대형 볶음솥·스팀/컨벡션 오븐·튀김기·배식 밧드로 만들 수 있는 메뉴를 선택한다. 가정용 프라이팬을 한 접시씩 돌리는 작업서는 쓰지 않는다.
- 같은 원재료의 전처리를 공유하되 메뉴를 복제하지 않는다. 주찬 세 개를 모두 즉석 튀김으로 짜서 배식 시간에 작업이 몰리지 않게 한다.
- 조리법과 재료가 완성된 등록 레시피를 우선 쓴다. 이름이 불명확하거나 확인 요청 중인 메뉴는 자동 후보에서 제외한다.

## 6. 자동 편성·수정 전 확인

1. 국 1개, 실속 있는 메인 2개, 김치, 곁들임이 있는가?
2. 주찬급 보강까지 합해 서로 다른 실속 메뉴가 3개 이상인가? 국·채소·후식으로 채운 것은 아닌가?
3. 고기/생선/해물 중심 메뉴가 있으며, 조합과 대량 조리 동선이 현실적인가?
4. 앞뒤 한 주의 실제 음식·별칭·조리 조합과 겹치지 않는가?
5. 새 메뉴의 레시피가 준비됐는가? 식수·직접 입력·가격·직원 자료는 유지되는가?

자동 생성은 이 매뉴얼을 우선으로 따르고 검증에 실패한 구성은 저장하지 않는다. 기존 식단 보정은 **오늘부터 예정된 AI 식단 중 기준에 어긋나는 끼니만** 대상으로 하고, 확인된 AI 작성 칸과 빈 추가 칸만 수정한다. 직접 수정한 식단 및 이미 지난 식단은 유지한다. 관리자용 AI 작성 이력은 남기되 외부 공지·인쇄물에는 AI 표시를 넣지 않는다.
